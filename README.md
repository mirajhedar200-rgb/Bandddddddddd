# Telegram Promo Bot

بوت إدارة حملات ترويج Telegram مع:
- شحن رصيد عبر سيريتل كاش + رقم عملية وموافقة الأدمن.
- باقات 500 / 1000 / 2000 / إعلان احترافي 3000+.
- خصم الرصيد عند إنشاء الطلب.
- مدة حملة تصل إلى 64 ساعة.
- نظام إحالات.
- لوحة أدمن.
- مساعد AI اختياري.
- Health endpoint مناسب لخدمة Render.

## مهم جداً
هذا المشروع لا يضيف أعضاء وهميين ولا يتحايل على Telegram، ولا يستطيع أي Bot API رسمي أن يضمن إضافة عدد محدد من مستخدمين حقيقيين إلى قناة/بوت. التنفيذ الواقعي يكون عبر حملات نشر في قنوات/شبكات ترويج يملك البوت أو مدير الحملة صلاحية النشر فيها.

للنشر التلقائي، أضف القنوات الشريكة التي وافقت على نشر الإعلانات، ثم طوّر وحدة `partner_channels`/الحملات لتوزيع الإعلان عليها. يجب أن يكون للبوت صلاحية النشر في القنوات المستهدفة.

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env` وضع القيم.
2. `pip install -r requirements.txt`
3. `python bot.py`

## Render
- ارفع الملفات إلى GitHub.
- أنشئ Web Service من المستودع.
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- أضف Environment Variables من `.env.example`.
- `ADMIN_ID` هو رقم حساب الأدمن، وليس اسم المستخدم.

### Render Free / النوم
لا يوجد "ثغرة" مضمونة لمنع النوم. الكود يوفر `/health` فقط. إذا كانت خطة الاستضافة تنام عند عدم وجود طلبات، يمكن استخدام مراقب خارجي مشروع لطلب `/health` وفق شروط الاستضافة. لا تعتمد على ping ذاتي من نفس الخدمة.

## Telegram
أنشئ البوت من @BotFather واحفظ BOT_TOKEN سرياً.

## القنوات الشريكة
من `/admin` افتح **📢 القنوات الشريكة**:
1. اضغط إضافة قناة.
2. أرسل @username للقناة أو Chat ID.
3. البوت يتحقق من أنه مشرف ولديه صلاحية نشر الرسائل.
4. يمكنك تفعيل/تعطيل أو حذف القنوات.
5. عند اعتماد طلب ترويج، يرسل البوت الإعلان إلى القنوات الشريكة النشطة.

يجب أن تكون القنوات موافقة فعلياً على استقبال الإعلانات. لا يحاول البوت النشر في قنوات لا يملك فيها صلاحية.
